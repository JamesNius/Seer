# Mortal v4 观测张量 (1012, 34) 完整通道表

## 概述

Mortal v4 的模型输入是一个 `(1012, 34)` 的浮点张量。  
1012 = 特征通道数，34 = 牌种类数（万1-9、饼1-9、索1-9、东南西北白发中、赤5万饼索）。

所有通道都是"可见牌面状态"编码，**没有任何手工推理特征**（筋/壁/安全度等）。模型完全通过强化学习隐式习得防守和牌效。

### SP 概率投影表详解

这是 v4 最大的创新——内置单玩家模拟器。对每张可切牌，预先计算未来 17 巡的：

| 行 | 内容 | 维度 |
|----|------|------|
| 听牌概率 | 第 N 巡听牌的概率 | 17 |
| 和牌概率 | 第 N 巡和牌的概率 | 17 |
| 期望价值 | 第 N 巡的 EV | 17 |

**3行 × 17巡 = 51 通道**。模型将这些搜索预览作为输入，学会如何利用"未来发牌模拟"辅助当前决策。

## 关键结论

1. **模型全靠自学**：1012 个通道中，仅 123 个 SP 投影属于"推理特征"，其余全是原始牌面状态
2. **没有手工防守规则**：筋/壁/早外/安全度 完全不存在
3. **SP 是搜索雏形**：v4 已将搜索结果嵌入观测，方向与腾讯AILab文章一致
4. **要扩展推理，方向明确**：对手手牌概率、牌山分布、听牌概率等可编码为新增通道
