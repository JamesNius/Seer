# Seer

A mahjong AI based on [Mortal](https://github.com/Equim-chan/mortal), with auxiliary oracle heads for enhanced analysis.

## Features

- **Version 4 Support**: Updated training pipeline for latest Mortal architecture
- **Oracle Auxiliary Heads**: Additional prediction heads for opponent hand analysis (used during training, optional at inference)
- **Engineering Tools**: Scripts for training, data processing, and evaluation
